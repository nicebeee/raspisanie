# Расписание техникума

Сайт для составления расписания на каждый день: учитывает доступность преподавателей, закреплённые аудитории, деление групп на подгруппы и ведёт учёт оставшихся пар по учебному плану.

Работает на GitHub Pages без сервера: всё расписание хранится в файле `data.json` этого репозитория.

## Как пользоваться

- **Все** открывают ссылку на сайт и видят утверждённое расписание на неделю — для группы, преподавателя или аудитории. На телефоне — по дням.
- **Администратор** нажимает «Войти» и вставляет личный токен GitHub. Открывается весь интерфейс. Изменения копятся в браузере (и не теряются при закрытии вкладки), кнопка «Сохранить» записывает их в `data.json`. У остальных сайт обновляется примерно через минуту.

### Токен администратора

1. GitHub → Settings → Developer settings → [Fine-grained tokens](https://github.com/settings/personal-access-tokens/new) → Generate new token.
2. Repository access → Only select repositories → этот репозиторий.
3. Permissions → Repository permissions → **Contents: Read and write**.
4. Скопировать токен и вставить на сайте в окно «Войти».

Чтобы добавить ещё одного администратора — пригласите его в Settings → Collaborators, и он создаст свой токен.

## Что умеет

- **Расписание на день** — сетка «группы × пары 1–6». Ячейку можно заполнить для всей группы или по подгруппам. Пару можно перетащить на другое время внутри группы. Справа — список ошибок и предупреждений; утвердить день можно только без ошибок.
- **Автосоставление** — кнопка «Автосоставление…» во вкладке «Расписание на день»: на день или неделю, для выбранных групп. Группу можно составить, только если у всех её предметов с оставшимися часами указан преподаватель — недостающих можно выбрать прямо в окне. Пары ставятся подряд без окон, с учётом доступности и занятости преподавателей, аудиторий и подгрупп; в первую очередь — предметы, по которым осталось больше часов, и разные предметы за день. Дни, где у группы уже есть пары, и утверждённые дни не меняются; результат — черновик.
- **Проверки:** не более 4 пар и без окон (для каждой подгруппы отдельно, её пары + общие пары группы); преподаватель — только в свои дни и пары и не в двух местах сразу; аудитория — не занята дважды; преподаватель с закреплённой аудиторией ставится только в неё; лабораторные/практические, отмеченные «по подгруппам», нельзя ставить всей группе; предупреждения о вместимости, типе аудитории и превышении часов.
- **Загрузка плана из Excel** — кнопка «Загрузить из Excel…» во вкладке «Учебный план». Подходит выгрузка «Учебный план» (.xls/.xlsx с листами «Титул» и «План»). Курс определяется по году начала подготовки (его можно поменять), часы двух семестров курса складываются в год, семинары и курсовое проектирование идут в практические. Практики (УП, ПП), экзамены и итоговые строки пропускаются. Можно загрузить в существующую группу (обновятся только часы) или сразу создать новую.
- **Учебный план** — по каждой группе: предметы, часы (всего, лекции, практические, лабораторные), проведено и осталось пар. Пары списываются при утверждении дня, отмена пары возвращает её в остаток. Для занятий по подгруппам счётчик ведётся на каждую подгруппу.
- **Преподаватели** — доступность по дням недели («с … по … пару»), закреплённая аудитория, даты отсутствия.
- **Аудитории, группы, подгруппы, предметы** — справочники.
- **Нагрузка**, **настройки** (звонки, лимит пар, часов в паре) и журнал изменений.

## Важно

- Репозиторий публичный: `data.json` может открыть любой. Поэтому у отсутствий хранятся только даты, без причины. Не вносите личные данные сверх ФИО.
- Если два администратора сохраняют одновременно, второй увидит предупреждение и выберет, чью версию оставить.
- Вся история изменений — в истории коммитов `data.json`, любую версию можно вернуть.

## Разработка

Сборки нет — обычные HTML, CSS и JS-модули.

- Посмотреть локально: `python3 -m http.server` в папке проекта и открыть http://localhost:8000 (вход на локальном адресе спросит ещё и имя репозитория).
- Тесты правил: `npm test` (нужен Node.js 18+).

Устройство:

- `index.html`, `styles.css` — страница.
- `js/app.js` — интерфейс.
- `js/store.js` — все действия с данными (поставить пару, утвердить, справочники).
- `js/logic.js` — правила проверки и подсчёт остатка пар.
- `js/autoschedule.js` — автосоставление расписания.
- `js/github.js` — чтение и сохранение `data.json` через GitHub API.
- `js/plan-import.js` — разбор учебного плана из Excel; `js/vendor/xlsx.mjs` — библиотека SheetJS 0.20.3 (Apache 2.0) для чтения Excel.
- `data.json` — данные (сейчас демо: 3 группы, 7 преподавателей, утверждённая неделя).
- `test/` — тесты правил.

Чего пока нет: выгрузки отчётов в Excel.
